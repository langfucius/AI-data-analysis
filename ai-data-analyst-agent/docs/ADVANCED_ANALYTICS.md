# 数据分析与图表使用指南

启动原入口，在主页切换 **业务分析 / 数据探索**。分析已合并到主工作台，不再需要单独打开“高级分析”：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app/ui/streamlit_app.py
```

## 数据探索

在“数据探索”选择真实 SQLite 表会加载一次结果；需要自定义查询时展开“SQL 查询（可选）”，检查预填的 `SELECT *`，点击“执行查询”。查询始终经过 `validate_sql`，再使用已有的只读 SQLite 连接和 authorizer 执行。切换源表会更新查询编辑器与快照；图表控件变化只读取已加载快照，不重新查询数据库。

在“业务分析”直接提问，回答先解释结果，再提供可切换的图表。原始数据、SQL 与导出放在回答下的折叠区，统计明细也可以按需展开。旧页面路径保留兼容，但不作为第二套工作流推荐。

概览显示加载行数、列数、缺失单元格、整行重复数、原始结果和描述统计。数据质量展示每列 dtype、缺失比例、唯一值数、常量标志、标识符标志、非有限数，以及 IQR 上下界和异常数。

统计范围是 **SQL 返回且被加载的行**，不一定是整张源表。系统限制 SELECT 的行数；即使 `truncated=False`，SQL 的 LIMIT 也可能省略源记录，因此页面始终说明统计范围。聚合查询的行数是聚合后的行数，不是订单总数。

## 图表探索

支持 bar、line、scatter、histogram、box、heatmap、pie。默认选用有效推荐配置，在“图表视角”切换业务指标，勾选“自定义图表与分组”后指定 X、Y、aggregation 和 group/color。每个回答只呈现一个当前图表；重新运行页面仍保留选择。

分类对比使用排序横条与数值标签；趋势线标注真实高点，较长日期序列提供范围滑块；热力图显示相关系数；饼图使用圆环与占比标签。所有图表都可悬停查看、缩放与下载 PNG，并与主页面深色风格一致。

- Bar：分类与数值；`count` 统计分类中的行数。
- Line：日期或数字 X，数值 Y；重复 X 必须聚合或分组，避免连出误导曲线。
- Scatter：两个数字列，只有明确询问变量关系时自动推荐。
- Histogram：数值 X，展示原始有限值的频率。
- Box：数值 X，或分类 X 与数值 Y；使用原始行。
- Heatmap：排除标识符后的数值相关矩阵。
- Pie：分类与非负数值，合计必须为正；最多十二类，否则建议柱状图。

聚合选项为 none、sum、mean、median、count、min、max。count 指行数，与 Y 的空值无关；其他聚合排除所选字段缺失值和非有限数字。缺失分类不编造为“其他”。原始数据不被转换或回写。

## 相关性与数据质量

Pearson 衡量线性相关；Spearman 使用平均秩；Kendall 使用支持并列值的 tau-b。每对变量独立排除缺失和正负无穷；有效样本不足或变量恒定时为未定义值，不用零伪装。Kendall 用树状数组计算，避免常规双重循环的平方复杂度。不依赖 SciPy。

日期识别支持已有 datetime dtype 和完整合法的 ISO 风格日期/月字符串，不把普通整数解析为纳秒时间。ID 数值列保留在描述统计中，但不会作为自动推荐的业务指标。

IQR 使用 Q1−1.5×IQR 和 Q3+1.5×IQR，仅标记可调查记录，不自动删除。重复数指首条之后的整行重复。分布对数字提供直方图区间，对分类提供前二十个非空值的频率；完整频率可通过 count 图表查看。

## AI 分析与导出

输入业务问题，运行已有 LangGraph Agent。显示 SQL、实际查询结果、统计证据、报告、修复次数和后续分析建议。Demo Mode 继续使用本地预定义问题；配置已存在的模型时使用原提供方。

报告先由 `business_insights.py` 生成业务解读：走势与高点、最近相邻月份变化、分组差距、已返回分组内占比、每单收入、变量关系和核查建议。每条结论都附带结构化证据，与图表使用同一结果。没有正数基期时不生成增长率，月份不连续时不称环比，部分结果不称全量份额，相关性不称因果。

AI 采用受约束的证据选择：模型只能返回证据 ID，程序根据 ID 输出已验证的统计或业务解读。模型提供的其他自由文本不展示。即使模型不可用，本地报告也能给出分析语言，而非只列 SQL 或均值。

导出支持 UTF-8 CSV、Markdown 摘要、严格 JSON 证据快照（非有限值输出 null）。CSV 保留原始文本，使用电子表格打开时应把文本列按文本导入。

查询错误时展示错误并明确保留上一次成功快照，不把旧结果冒充本次结果。图表配置错误显示原因，不替用户静默更改指标。
